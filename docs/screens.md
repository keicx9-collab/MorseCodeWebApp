## 4. 画面一覧・遷移### 4.1 画面一覧本アプリは単一画面（シングルアクティビティ）構成とし、入力状態に応じて表示内容を動的に更新する。| 画面ID | 画面名 | 概要 || :--- | :--- | :--- || SCR-01 | メインシミュレーター画面 | 二分木、各アルファベットLED、入力ボタンを表示する本アプリのメイン画面。 |### 4.2 画面遷移図単一画面内での「状態遷移（ステート遷移）」として定義する。```mermaidgraph TD    %% 状態の定義    START((開始/リセット))    WAIT[入力待ち：アンテナ点灯]    INPUT_ACTION{ボタン押下}    MOVE_ROUND[短点ノードへ遷移：丸型LED点灯]    MOVE_RECT[長点ノードへ遷移：長方形LED点灯]    END_NODE[末端ノード到達]        %% 遷移の定義    START --> WAIT    WAIT -->|短押し| MOVE_ROUND    WAIT -->|長押し| MOVE_RECT        MOVE_ROUND -->|短押し| MOVE_ROUND    MOVE_ROUND -->|長押し| MOVE_RECT    MOVE_RECT -->|短押し| MOVE_ROUND    MOVE_RECT -->|長押し| MOVE_RECT        MOVE_ROUND -->|一定時間無操作| START    MOVE_RECT -->|一定時間無操作| START        MOVE_ROUND -->|末端到達| END_NODE    MOVE_RECT -->|末端到達| END_NODE    END_NODE -->|一定時間無操作| START```### 4.3 遷移の詳細仕様1.  **初期表示（アイドル状態）**    *   アプリ起動時、およびリセット時は、ツリー最上部の「アンテナ」をアクティブ（強調表示）とする。    *   その他の全てのノード（LED）は非点灯（グレーアウト等）とする。2.  **ノード間遷移**    *   ユーザーのボタン操作（短押し/長押し）を受け取るたびに、現在のアクティブノードから、下位の対応するノードへターゲットを移動させる。    *   移動先のノード（LED）を点灯状態にする。3.  **自動リセット（タイムアウト）**    *   最後のボタン操作から一定時間（例：1.5秒〜2秒）経過した場合、入力が完了したとみなし、アクティブな位置を「アンテナ（初期状態）」へ戻す。
