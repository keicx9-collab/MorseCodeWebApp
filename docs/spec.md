# アプリ要件定義書：MorseCodeTestApp## 1. プロジェクト概要*   **アプリ名:** MorseCodeTestApp*   **ターゲットOS:** Android*   **目的:** モールス信号の構造（二分木）を視覚的にシミュレートし、ユーザーの入力操作を通じて信号の仕組みを学習・体験する。## 2. 画面構成### 2.1 メインインターフェース添付画像（MorseCodePracticeCard_0.png、MorseCodePracticeCard_1.jpg、MorseCodePracticeCard_2.jpg）をモデルとした、モールス信号の二分木（バイナリツリー）レイアウトを描画する。*   **ルートノード:** 画面最上部中央に「アンテナ」アイコンを配置。*   **子ノード（LED）:**    *   **短点用:** 丸型のLEDデザイン。    *   **長点用:** 長方形（横長）のLEDデザイン。    *   各ノードには、対応するアルファベットを併記する。*   **入力デバイス:** 画面中央の最下部に、操作用のメインボタンを1つ配置する。## 3. 機能要件### 3.1 入力操作*   **短押し判定:** ユーザーがボタンを短くタップした際に「短点（ディ）」として認識する。*   **長押し判定:** ユーザーがボタンを一定時間以上保持した際に「長点（ダー）」として認識する。### 3.2 音声出力*   ボタンの押下時間に同期して、リアルタイムでビープ音を鳴らす。### 3.3 二分木遷移シミュレーション（LED制御）*   **初期状態:** 画面上部のアンテナアイコンがアクティブな状態で開始。*   **遷移動作:**    *   現在のノードから、入力（短押し/長押し）に応じてツリーの下層へと順次移動する。    *   **短押し時:** ツリー上の「丸ボタン（短点）」側のLEDを点灯させ、そのノードへ遷移する。    *   **長押し時:** ツリー上の「長方形ボタン（長点）」側のLEDを点灯させ、そのノードへ遷移する。*   **点灯仕様:** ボタンが押されている間、対応するノードのLEDが点灯する。## 4. 動作仕様（振る舞い）*   **入力の継続:** 一つの文字が完成するまで、前の入力結果を引き継いでツリーを下っていく。*   **リセット条件:** (例) 一定時間（2〜3秒など）操作がない場合、アクティブな位置をルート（アンテナ）へ戻す。*   **境界条件:** ツリーの末端（リーフノード）に達した後の入力は無視するか、あるいはリセット処理を行う。## 5. 補足事項*   本ドキュメントでは、特定のデザインパターンや内部ディレクトリ構造などのアーキテクチャについては定義しない。実装者は自由な設計手法で上記振る舞いを実現すること。
